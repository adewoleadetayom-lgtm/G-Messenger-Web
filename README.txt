G MESSENGER — INDEPENDENT WEB VERSION
=====================================

This is a standalone browser version. It intentionally has NO verification page.

Features included:
- Direct opening to Chats
- Chats and separate chat rooms
- Official G Messenger channel
- Updates / Status
- Communities
- Calls UI
- Gemma AI interface
- New contacts
- Profile and settings
- Light/dark appearance
- Browser localStorage so website data persists

IMPORTANT:
This folder is independent from the Android app. It does not modify the Android project.

To test:
1. Open index.html in a browser.
2. For a public unique URL, upload this folder to a static host such as GitHub Pages, Netlify, or Cloudflare Pages.
3. The public URL will be separate from the Android app.
